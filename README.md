Retail Sales Insights – Tableau Dashboard

Project Overview

An interactive Tableau dashboard built to analyze retail sales data and uncover meaningful business insights.

Dashboard Features

* Sales, Profit, and Profit Margin KPIs.
* Sales analysis by Category and Region.
* Monthly Order Trends.
* Customer Segment Analysis.
* Interactive Filters for deeper exploration.

Tools & Technologies

* Tableau
* Superstore Dataset
* Data Visualization
* Business Intelligence

Objective

To transform retail sales data into clear and interactive visual insights that help understand business performance and sales trends.
